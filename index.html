Перетворення простого двійкового коду в ДДК (BCD 8421)

Основні характеристики ДДК (8421) [За методичкою]:
Характеристика Позначення / Формула Значення
Основа коду m 2 (двійковий)
Довжина ДДК комбінації n = 4 × (кількість цифр) -
Повне число комбінацій N = mn = 2n -
Потужність коду (робочі комбінації) Np = 10(кількість цифр) -
Кількість перевірочних (надлишкових) розрядів r = n - ⌈log2 Np⌉ -
Відносна надлишковість коду R = 1 - (log2 Np / n) -
